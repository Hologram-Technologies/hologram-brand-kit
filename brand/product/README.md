# Hologram product desk

One folder per feature. Each folder holds a five minute spec with the user
journey as a diagram, and live wireframes built from the component library.
Copy [TEMPLATE.md](TEMPLATE.md) to start a feature. Register screens in
[brand/showcase/src/screens](../showcase/src/screens); the build fails if a
registered screen has no spec, and screenshots regenerate with
`node brand/scripts/shoot-screens.mjs`.

All screens, live: [the screens index](https://hologram-technologies.github.io/hologram-brand-kit/#/screens)
